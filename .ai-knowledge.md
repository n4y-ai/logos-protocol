# Logos Protocol - AI Knowledge Base

## Project Overview

Logos Protocol is the blockchain layer for the Logos ecosystem - AI-powered digital twins.

**Repository:** https://github.com/n4y-ai/logos-protocol
**Chain:** Base Mainnet (8453)
**Tech Stack:** Solidity 0.8.28, Hardhat, OpenZeppelin

## Smart Contracts

### NameRegistry (Deployed ✅)
- **Address:** `0x0Eb28d2b84F48CE18742f6C42C5BA18c17b0d4E3`
- **Purpose:** Global unique handle registry
- **Handle Rules:** Base36 (A-Z, 0-9), uppercase, 4-10 chars
- **Functions:** `isAvailable()`, `resolve()`, `reverseResolve()`, `registerName()`

### LogosAccount (Ready for deployment)
- **Purpose:** Smart account with two-key architecture
- **Owner Key:** Full control, user's encrypted key
- **Agent Key:** Limited access, backend-stored AI key
- **Functions:** `getDID()`, `setAgent()`, `execute()`, `verifySignature()`

### LogosAccountFactory (Ready for deployment)
- **Purpose:** Creates LogosAccount + registers handle atomically
- **Depends on:** NameRegistry address

## Two-Key Architecture

```
┌─────────────────────────────────────────────┐
│             LogosAccount                     │
│  ┌─────────────┐    ┌─────────────┐         │
│  │ Owner Key   │    │ Agent Key   │         │
│  │ (User)      │    │ (AI/Backend)│         │
│  │ Full Control│    │ Limited     │         │
│  └─────────────┘    └─────────────┘         │
└─────────────────────────────────────────────┘
```

- **Owner Key:** Generated in browser, encrypted with password, stored in localStorage
- **Agent Key:** Generated on backend, stored encrypted in database
